# Lokal logo

The mark is `[L]`: the L of Lokal inside the brackets of a Samaran placeholder such as `[NIK_1]`, in merah putih.

| File | Use |
|---|---|
| `lokal-mark.svg`, `lokal-mark.png` | The mark on its own: icons, favicons, small spaces |
| `lokal-mark-dark.svg` | The mark on a dark tile, for light backgrounds that need contrast |
| `lokal-wordmark.svg` | Mark and name, for light backgrounds |
| `lokal-wordmark-white.svg` | Mark and name, for dark backgrounds |
| `lokal-avatar.png` | Square avatar for GitHub, npm, and social accounts (the platform rounds the corners) |

Colors: red `#E5262E`, white `#FFFFFF`, ink `#111827`.

The name is set in [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans) ExtraBold by Tokotype, under the SIL Open Font License 1.1, converted to outlines.
