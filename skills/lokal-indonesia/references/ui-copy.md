## Patterns

- Empty state: "Belum ada pesanan." + an action ("Mulai belanja").
- Confirmation: "Hapus alamat ini?" with buttons "Hapus" / "Batal" — the button repeats the verb.
- Toast after success: past-tense, short: "Alamat disimpan."
- Avoid: "Silakan untuk…", "Apakah Anda yakin ingin untuk…", "Klik di sini untuk…", and English word order calques ("Login berhasil dilakukan").
